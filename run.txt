                              QUICK START GUIDE
================================================================================

## 1️⃣ INITIAL SETUP (After Cloning)

### Step 1: Install Dependencies

A. Frontend (React Native App):
   ```bash
   cd ui
   npm install --legacy-peer-deps
   ```
   
   Note: Use --legacy-peer-deps to resolve peer dependency conflicts.
   Expected: ~1004 packages will be installed.

B. Backend (Python FastAPI):
   ```bash
   cd geofencing_module
   pip install -r requirements.txt
   ```
   
   Or if you have system Python packages:
   ```bash
   sudo apt-get update
   sudo apt-get install -y python3-shapely python3-geopy
   pip install fastapi uvicorn sqlalchemy python-jose passlib bcrypt pydantic
   ```

### Step 2: Database Setup (Backend)

The database (tourists.db) is already included. To reset or recreate:

```bash
cd geofencing_module

# Option 1: Run migration for existing database
python3 migrate_add_last_updated.py

# Option 2: Recreate database from scratch
rm tourists.db
python3 -c "from app import Base, engine; Base.metadata.create_all(bind=engine)"
python3 seed.py
```

### Step 3: Configure Environment (Optional)

The default backend URL is `http://localhost:8000` for local development.

If testing on a physical device or emulator on a different network, create or update the .env file in the ui/ directory:

```bash
cd ui
echo "EXPO_PUBLIC_API_BASE=http://YOUR_IP_ADDRESS:8000" > .env
```

Replace `YOUR_IP_ADDRESS` with your computer's local network IP (e.g., 192.168.1.x).

================================================================================
                            RUNNING THE APPLICATION
================================================================================

## 2️⃣ START BACKEND SERVER (Terminal 1)

```bash
cd geofencing_module
python3 -m uvicorn app:app --host 0.0.0.0 --port 8000 --reload
```

Expected output:
✅ INFO:     Uvicorn running on http://0.0.0.0:8000
✅ INFO:     Application startup complete.

Backend will be available at: http://localhost:8000
API Docs: http://localhost:8000/docs

## 3️⃣ START FRONTEND APP (Terminal 2)

```bash
cd ui
npm run dev
```

Alternative commands:
- `npm start` - Standard Expo start
- `expo start` - If you have Expo CLI globally installed

Expected output:
✅ Starting Metro Bundler
✅ Waiting on http://localhost:8081
✅ Metro is running

## 4️⃣ OPTION A: Using Expo Go App (Recommended for Testing)

### Setup:
1. Install "Expo Go" app on your phone:
   - iOS: https://apps.apple.com/app/expo-go/id982107779
   - Android: https://play.google.com/store/apps/details?id=host.exp.exponent

2. Make sure your phone and computer are on the same Wi-Fi network.

### Scan QR Code:
- Once Metro bundler starts, you'll see a QR code in the terminal
- iOS: Open Camera app → Point at QR code → Tap notification
- Android: Open Expo Go app → Tap "Scan QR Code" → Scan

### Manual Connection (if QR doesn't work):
- In terminal, press 's' to switch to connection string
- Note the exp://YOUR_IP:8081 URL
- Open Expo Go → Enter URL manually

```bash

# Or run:
npm run web
```

================================================================================
                           TROUBLESHOOTING GUIDE
================================================================================

## Problem: "Cannot find module" or dependency errors

Solution:
```bash
cd ui
rm -rf node_modules package-lock.json
npm install --legacy-peer-deps
```

## Problem: Backend not connecting / Network error

Solution:
1. Check if backend is running on port 8000
2. For local development on the same machine, use `http://localhost:8000` (default)
3. For testing on physical devices or remote emulators, update API URL in ui/.env:
   ```
   EXPO_PUBLIC_API_BASE=http://YOUR_COMPUTER_IP:8000
   ```
4. Find your computer's local network IP:
   - macOS/Linux: `ifconfig | grep inet` or `ip addr show`
   - Windows: `ipconfig`
5. Use your local network IP (e.g., 192.168.1.x), not 127.0.0.1 when accessing from other devices

## Problem: Expo Go shows "Unable to resolve" error

Solution:
1. Clear Metro bundler cache:
   ```bash
   cd ui
   npx expo start --clear
   ```
2. Restart Metro bundler (Ctrl+C then npm run dev again)

## Problem: QR Code not scanning

Solution:
1. Make sure phone and computer are on same Wi-Fi
2. Use manual connection string (press 's' in terminal)
3. Try opening in browser: http://YOUR_IP:8081

## Problem: Location permissions not working

Solution:
1. Go to phone Settings → Apps → Expo Go → Permissions
2. Allow Location access
3. Restart the app

## Problem: Database errors (Backend)

Solution:
```bash
cd geofencing_module
# Backup existing database
cp tourists.db tourists.db.backup
# Run migration
python3 migrate_add_last_updated.py
# Or recreate from scratch
rm tourists.db
python3 -c "from app import Base, engine; Base.metadata.create_all(bind=engine)"
python3 seed.py
```
